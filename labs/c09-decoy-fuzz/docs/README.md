# C09 — Decoy discipline: 40 hosts, 1 real, zero false positives

**Case:** C9 (writeup para 30, triage discipline). **Ports:** 18160 / 18523. **Time:** 25 min.

## Objective

Same sweep as C03, but adversarial: 39 look-alikes, including catch-alls that answer 200 to every path
and 8 hosts whose response headers claim to be the real one. Your job is precision — one hit, no
noise.

## What you get

- `https://127.0.0.1:18523` — 40 vhosts.
- `edge/sites.json` is generated by `gen.py`; the label list is `_shared/data/vhost-labels.txt` plus
  `app01..app16`.

## Traps

- 2 catch-alls: 200 on **every** path, so "status 200" is not evidence.
- 8 lures: `X-Forwarded-Host: chatadmin.corp.lab` and `X-Backend: chatadmin` on their responses.
- 39 byte-identical roots: length triage finds nothing.

## Success criterion

`bash checks/verify.sh`. As a human: exactly one host serves the app marker, and you can name the trap
that nearly fooled you.

## Hints

1. Score on **body content** (`Chat Admin`), never on status.
2. Headers are claims. A decoy echoing `X-Forwarded-Host: chatadmin.corp.lab` is telling you what it
   *wants* you to think.
3. Catch-alls fall over on a second path: request `/robots.txt` and compare with `/app`.
4. Write the finding only after two independent paths agree.
