Port map: HTTPS `18443 + 10*(n-1)`, HTTP `18080 + 10*(n-1)`; c00 sits at the end (18180/18543), c11 after it (18190/18553).
Subnets: `172.28.(10*n).0/24`. All ports are published on `0.0.0.0` — `make lan` prints the LAN
address and a client hosts file, `LAB_HOST=<lan-ip> make verify-all` grades over the LAN path.

Each lab's walkthrough exists as `docs/solution.txt` (plain text, commands + expected output) and
`docs/solution.md`; `solutions/ALL_SOLUTIONS.txt` concatenates all twelve, `solutions/INDEX.txt` maps
lab → file. Regenerate with `bash scripts/build-solutions.sh` after editing a walkthrough.

## Shared components

- `vhostlab/edge:1.0` — routing rules live in each lab's `edge/sites.json`: exact hosts, keyword rules
  (`contains`/`suffix`/`prefix`, case/port/trailing-dot policy), per-rule `Server:` header, local
  status bodies, path rewrites, SNI cert map.
- `vhostlab/api:1.0` — env-driven: `DEBUG`, `BROWSABLE`, `EMAIL_HOST/PORT`, `FLAG`, `JWT_KEY`,
  `ADMIN_EMAIL`, `DB_PATH`. Same image, different behaviour per lab.
- Lab CA — `_shared/certs/out/ca.crt`; per-lab leaf in `labs/*/edge/certs/`.

## Difficulty

C01/C02/C08 are observation drills (10-15 min). C03/C04/C05/C09 are sweep-and-triage (20-30 min).
C06 is setup work (browser trust). C07 is the exploit (35 min). C10 is the pattern you asked for plus
normalisation gaps (30 min). C11 is silence-as-a-control: 20 min, mostly tooling discipline. C00 is the sequence (60-90 min) and the only lab where the reportable
question matters.
